# MSU Terrain — استخراج عوارض با DEM و DSM

برنامهٔ فارسی **کاملاً آفلاین برای ویندوز ۶۴بیتی** برای استخراج پیکسل‌های مرتفع بر اساس **ارتفاع از زمینِ همان نقطه**. رابط در مرورگر دستگاه خودتان باز می‌شود؛ تمام پردازش و نگهداری فایل‌ها روی همان دستگاه است. اینترنت، حساب کاربری، سرور ابری و کلید API لازم نیست.

## دانلود و اجرای نسخهٔ آفلاین ویندوز

[دانلود مستقیم بستهٔ Windows x64 از GitHub](https://github.com/davidkordmir-source/MSU-DEM-DSM/raw/refs/tags/v0.2.0-offline/downloads/MSU-Terrain-Windows-x64.zip)

1. فایل ZIP را یک بار دانلود و **همهٔ محتویات آن را خارج کنید**. آن را داخل یک پوشهٔ قابل‌نوشتن مانند Documents قرار دهید.
2. اینترنت را می‌توانید قطع کنید. فایل **`Start-MSU-Terrain.cmd`** را دوبار کلیک کنید.
3. مرورگر پیش‌فرض روی نشانی محلی `127.0.0.1` باز می‌شود. اگر مرورگر خودکار باز نشد، نشانی نمایش‌داده‌شده در پنجرهٔ برنامه را در Edge، Chrome یا Firefox باز کنید.
4. پنجرهٔ برنامه را باز نگه دارید؛ برای خروج `Ctrl+C` بزنید یا پنجره را ببندید.

این بسته قابل‌حمل است: **نصب Python، pip، uv، کتابخانه یا دسترسی مدیر سیستم لازم نیست**. Python رسمی، GDAL/PROJ و پایگاه مختصات، همهٔ کتابخانه‌ها، قلم و رابط داخل ZIP هستند. ویندوز ۱۰ یا ۱۱ نسخهٔ x64 و یک مرورگر نصب‌شده لازم است؛ دستگاه ARM و ویندوز ۳۲بیتی هدف این بسته نیستند.

برنامه فقط روی loopback گوش می‌دهد؛ در شبکهٔ محلی یا اینترنت سروری منتشر نمی‌کند. دانلود خودکار پایگاه مختصات PROJ غیرفعال است؛ درخواست‌های خارجی Python نیز در راه‌انداز آفلاین مسدود می‌شوند. فونت، اسکریپت و استایل از CDN دریافت نمی‌شوند. ساخت بسته در محیط توسعه به اینترنت نیاز دارد، اما **اولین اجرا و همهٔ اجراهای بعدی بستهٔ آماده آفلاین‌اند**.

برای کنترل سلامت بسته می‌توانید checksum موجود کنار فایل ZIP در `downloads/` را با SHA-256 دانلود مقایسه کنید. فهرست hash فایل‌های داخل بسته در `MANIFEST.sha256.json` و مشخصات منابع رسمی در `DEPENDENCIES.json` قرار دارند. با دستور `runtime\python.exe -I offline_smoke.py` در پوشهٔ بسته، آزمون آفلاین محاسبات نیز اجرا می‌شود.

```text
height_above_ground = DSM − DEM
selected = height_above_ground > threshold_in_metres

DEM = −100 m, DSM = −50 m → height = 50 m → selected for threshold 30 m
```

## اجرای سورس برای توسعه‌دهندگان

Python 3.12 و [uv](https://docs.astral.sh/uv/getting-started/installation/) پیشنهاد می‌شود. در پوشهٔ پروژه:

```sh
uv sync --frozen
uv run --offline python -I run_offline.py
```

راه‌انداز یک پورت آزاد محلی انتخاب و مرورگر را باز می‌کند. برای پورت ثابت از `--port 8000` و برای جلوگیری از بازشدن خودکار مرورگر از `--no-browser` استفاده کنید. روی لینوکس یا macOS پس از نصب اولیهٔ وابستگی‌های توسعه، `bash run.sh` نیز همین کار را انجام می‌دهد و هیچ نصب یا دانلودی هنگام اجرا انجام نمی‌دهد. روش سورس به آماده‌سازی اولیه نیاز دارد؛ بستهٔ Windows x64 بالا تمام پیش‌نیازها را همراه دارد.

روش جایگزین بدون uv:

```sh
python -m venv .venv
# Linux/macOS:
.venv/bin/python -m pip install --require-hashes -r requirements.txt
.venv/bin/python -I run_offline.py
# Windows: به جای .venv/bin/python از .venv\Scripts\python.exe استفاده کنید.
```

## استفاده

1. DEM زمین و DSM سطح را انتخاب کنید: GeoTIFF تک‌باند با CRS معتبر، حداکثر ۵۱۲ مگابایت و ۵۰۰ میلیون پیکسل برای هر فایل.
2. واحد ارتفاع هر ورودی را تعیین کنید: متر، فوت بین‌المللی یا فوت پیمایشی آمریکا. `scale` و `offset` باند قبل از تبدیل واحد اعمال می‌شوند.
3. آستانهٔ ارتفاع از زمین را بر حسب متر وارد کنید. پیش‌فرض «بزرگ‌تر از» است؛ «بزرگ‌تر یا مساوی» نیز در دسترس است.
4. یکسان بودن **مبنای ارتفاعی** فایل‌ها را تأیید کنید و تحلیل را اجرا کنید. مثلاً ارتفاع بیضوی و ارتفاع از سطح متوسط دریا باید پیش از استفاده به مبنای مشترک تبدیل شوند.
5. لایهٔ ارتفاع نسبی، سطح DSM یا ماسک انتخاب را بررسی کنید. با کشیدن نقشه جابه‌جا شوید و با دکمه‌ها یا چرخ ماوس بزرگ‌نمایی کنید. خروجی‌ها را جداگانه یا در ZIP دریافت کنید.

«امتحان با دادهٔ نمونه» دو مدل مصنوعی زیر سطح دریا تولید می‌کند و **همان مسیر محاسبهٔ واقعی** را اجرا می‌کند. این داده برداشت واقعی یک منطقه نیست.

## اختلاف تفکیک‌پذیری و سیستم مختصات

- شبکهٔ DSM مرجع است: CRS، ابعاد، جهت و تبدیل مکانی آن در خروجی حفظ می‌شود. خود DSM بازنمونه‌برداری نمی‌شود.
- DEM روی شبکهٔ DSM بازنمونه‌برداری و در صورت نیاز تبدیل مختصات می‌شود. در حالت خودکار، DEM درشت‌تر با **bilinear** و DEM ریزتر با **average** تبدیل می‌شود. با CRS متفاوت، اندازهٔ تقریبی پیکسل DEM در CRS مقصد برای انتخاب روش استفاده می‌شود. انتخاب دستی bilinear، average و nearest نیز ممکن است.
- شبکه‌های یکسان بدون درون‌یابی خوانده می‌شوند. اختلاف مکان پیکسل‌ها حتی در اندازهٔ برابر نیازمند هم‌مکان‌سازی است.
- DEM ده‌متری و DSM نیم‌متری خروجی نیم‌متری می‌دهند. **تفکیک‌پذیری خروجی به معنی دقت واقعی نیم‌متری DEM نیست.** خطای زمین می‌تواند باعث انتخاب یا حذف عوارض نزدیک آستانه شود.
- فقط پیکسل‌های معتبر در هر دو ورودی محاسبه می‌شوند. NoData، ماسک اعتبار داخلی GeoTIFF، NaN، Inf و نواحی بدون پوشش مشترک حذف می‌شوند. ماسک خارجی و فایل‌های جانبی در ورودی تک‌فایلی پشتیبانی نمی‌شوند.
- محاسبه با float64 انجام و خروجی ارتفاع با float32 ذخیره می‌شود. حاشیه‌ای در حد گردکردن float64 مانع عبور اشتباه مقدار دقیق آستانه هنگام درون‌یابی می‌شود.
- مساحت گزارش‌شده در CRS تصویرشده، مساحت شبکه‌ای با تبدیل واحد افقی به متر است؛ برای CRS جغرافیایی گزارش نمی‌شود. این عدد مساحت ژئودزیک یا شیب‌دار نیست.

## خروجی‌ها

| فایل | محتوا |
| --- | --- |
| `height.tif` | تمام ارتفاع‌های معتبر `DSM − DEM` بر حسب متر؛ مقادیر منفی حفظ می‌شوند؛ NoData برابر NaN |
| `extracted.tif` | ارتفاع از زمین فقط برای پیکسل‌های عبورکرده از آستانه؛ سایر پیکسل‌ها NaN |
| `mask.tif` | ۱ منتخب، ۰ معتبر و غیرمنتخب، ۲۵۵ نامعتبر یا فاقد هم‌پوشانی |
| `report.json` | آمار، آستانه، روش تبدیل، مشخصات ورودی‌ها، منابع و محدودیت‌ها |
| `results.zip` | چهار فایل بالا با مختصات کامل و تفکیک‌پذیری اصلی DSM |

ارتفاع به‌تنهایی **ساختمان را از درخت و دیگر عوارض بلند تفکیک نمی‌کند**؛ این کار دادهٔ مکمل یا مدل طبقه‌بندی نیاز دارد. خروجی این نسخه رستری است، نه مرز برداری ساختمان.

## کارایی و منابع

- تعداد هسته‌های CPU از affinity و محدودیت cgroup استخراج می‌شود. GDAL برای بازنمونه‌برداری و فشرده‌سازی از هسته‌های در دسترس استفاده می‌کند.
- پردازش در پنجره‌های ۱۰۲۴ × ۱۰۲۴ است (۵۱۲ در حافظهٔ کمتر از ۲ گیگابایت)؛ کل رستر در حافظه بارگذاری نمی‌شود.
- کش GDAL حداکثر ۲۵٪ حافظه تا سقف ۴ گیگابایت و حافظهٔ warping حداکثر ۱۲٫۵٪ تا سقف یک گیگابایت است. بودجه برای جلوگیری از مصرف تمام RAM محدود می‌شود.
- یک کار پردازشی در هر لحظه اجرا می‌شود. حداکثر سه کار، شامل بارگذاری و کار جاری، پذیرفته می‌شود. Uvicorn را با **یک worker** اجرا کنید.
- نمایش نقشه با WebGL، `powerPreference: high-performance`، نسبت پیکسل دستگاه و رسم فقط هنگام تغییر انجام می‌شود. انتخاب واقعی GPU به مرورگر و سخت‌افزار بستگی دارد؛ حالت Canvas برای نبود WebGL وجود دارد. پردازش ژئورستری با CPU انجام می‌شود و این برنامه از CUDA استفاده نمی‌کند.
- پیش‌نمایش حداکثر ۲۰۴۸ پیکسل در ضلع بلند است (۱۰۲۴ در سیستم کم‌حافظه)؛ GeoTIFF خروجی کاهش تفکیک‌پذیری ندارد. رنگ‌ها برای نمایش کشیده می‌شوند و جایگزین مقدار عددی رستر نیستند. عوارض کوچک ممکن است در پیش‌نمایش کاهش‌یافته دیده نشوند.
- استفادهٔ دائمی از ۱۰۰٪ CPU/GPU تضمین نمی‌شود؛ سرعت به دیسک، فشرده‌سازی، روش تبدیل و اندازهٔ منطقه بستگی دارد.

## داده‌های موقت و استقرار

در بستهٔ آفلاین، فایل‌ها فقط روی دستگاه خودتان، کنار برنامه و در `.data/` ذخیره می‌شوند. ورودی‌ها بعد از پایان کار حذف می‌شوند. خروجی‌های قدیمی‌تر از ۲۴ ساعت هنگام پذیرش کار بعدی پاک‌سازی می‌شوند؛ فایل‌های موردنیاز را دریافت کنید. کار تکمیل‌شده پس از راه‌اندازی مجدد قابل بازیابی است؛ کار نیمه‌تمام نیازمند ارسال دوباره است. متغیر اختیاری `MSU_DATA_DIR` محل ذخیره را تغییر می‌دهد. نسخهٔ سورس امکان اجرای سرور روی سیستم دیگری را دارد؛ این حالت از اجرای محلی بستهٔ آفلاین جداست.

این نسخه برای استفادهٔ شخصی یا محیط مورداعتماد آماده شده است. برای انتشار عمومی، احراز هویت، سهمیهٔ کاربران، محدودیت درخواست در reverse proxy و سیاست نگهداری داده اضافه کنید. در محیط ابری از checkout موجود استفاده کنید؛ ایجاد Git worktree نیاز نیست. فرآیند سرور پس از بازیابی snapshot باید دوباره اجرا شود.

## آزمون‌ها

```sh
uv sync --frozen
uv run pytest -q
uv run ruff check app tests
```

آزمون‌ها شامل ارتفاع منفی از سطح دریا، مرز آستانه، گردکردن درون‌یابی، حالت بدون انتخاب، NoData، ماسک داخلی، ارتفاع منفی، واحد فوت و scale/offset، هر دو جهت تبدیل ۱۰ متر و نیم‌متر، CRS متفاوت، عدم هم‌پوشانی، فایل خراب، API بارگذاری، دانلود و بازیابی نتیجه هستند.

آزمون مرورگر در حالی که برنامه با `--port 8000 --no-browser` اجراست:

```sh
uv sync --frozen --group browser
# Chromium موجود استفاده می‌شود؛ مسیر پیش‌فرض /usr/bin/chromium است.
# متغیر CHROMIUM_PATH مسیر اجرایی دیگری را تعیین می‌کند.
uv run --group browser python tests/browser_smoke.py
```

آزمون مرورگر درخواست‌های خارجی را مسدود می‌کند و نمونه، بارگذاری واقعی DEM ده‌متری/DSM نیم‌متری، دریافت ZIP، بازیابی پس از refresh، اعتبارسنجی، تغییر لایه، بزرگ‌نمایی و عرض‌های ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل را بررسی می‌کند. تصاویر در `test-results/` ذخیره می‌شوند. WebGL در headless ممکن است از renderer نرم‌افزاری استفاده کند؛ عبور این آزمون بنچمارک GPU فیزیکی نیست.

## بازسازی بستهٔ ویندوز

```sh
python tools/build_windows_bundle.py
```

این مرحله مخصوص سازنده و نیازمند اینترنت است. ابزار از NuGet رسمی Python Software Foundation و PyPI دانلود می‌کند و همهٔ hashهای قفل‌شده در `packaging/windows-lock.json` را کنترل می‌کند. پس از استخراج runtime و wheelهای x64، بستهٔ مستقل در `downloads/` ساخته می‌شود. هیچ دادهٔ کاربر، محیط مجازی توسعه، تنظیمات احراز هویت یا پوشهٔ `.data` داخل بسته قرار نمی‌گیرد.

قلم Vazirmatn تحت SIL Open Font License توزیع شده است؛ مجوز در `app/static/fonts/OFL.txt` موجود است.
